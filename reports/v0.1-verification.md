## Known limitations

1. Forge adapter exercises Forge's **provider layer**, not full agent orchestration (roadmap).
2. Rubric judge-model mode not enabled in v0.1 (offline keyword heuristic only; skips otherwise).
3. Single-repetition runs give low-confidence decisions; no confidence intervals yet (v0.2).
4. HTML report is a minimal escaped shell, not a styled dashboard (v0.2).
5. Cost figures are user-configurable estimates, never measured billing.
6. Exotic terminals may need `PYTHONIOENCODING=utf-8` for Unicode output.
